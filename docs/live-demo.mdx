The FileKit sample app is built with Compose Multiplatform and compiled to WebAssembly. It runs the same code as the Android, iOS and desktop samples, with FileKit handling every dialog through the browser APIs.

<FileKitDemo title="FileKit sample" height={680} />

<Note>
The browser limits what a web page can do with files. File and directory pickers work in modern browsers. The camera picker and share sheet are Android and iOS only, and the file saver dialog is not available on the web, so the sample marks them as unsupported here. On the web, use [`FileKit.download()`](/dialogs/file-saver) to save files. Each page lists the supported platforms.
</Note>

## Run it locally

The source lives in [`sample/webApp`](https://github.com/vinceglb/FileKit/tree/main/sample/webApp) and [`sample/shared`](https://github.com/vinceglb/FileKit/tree/main/sample/shared).

```bash
./gradlew :sample:webApp:wasmJsBrowserDevelopmentRun
```

Add `?demo=file-picker` to the URL to open a screen directly. The available screens are `file-picker`, `gallery-picker`, `directory-picker`, `camera-picker`, `file-saver` and `share-file`.
