`FileKit.compressImage` re-encodes an image as JPEG or PNG, optionally downscaled, and returns the new bytes. It is declared in `nonWebMain` and throws a `FileKitException` on Linux native, Windows native, and watchOS.

## Usage

```kotlin nonWebMain
val compressed: ByteArray = FileKit.compressImage(
    file = photo,
    quality = 80,
    maxWidth = 1024,
    maxHeight = 1024,
)
(FileKit.cacheDir / "photo-small.jpg").write(compressed)
```

Pass `bytes = imageBytes` instead of `file` when the image is already in memory.

## Options

| Parameter | Values | Default | Notes |
| --- | --- | --- | --- |
| `file` or `bytes` | `PlatformFile` or `ByteArray` | Required | The source image. |
| `imageFormat` | `ImageFormat.JPEG`, `ImageFormat.PNG` | `JPEG` | Output format. |
| `quality` | `0` to `100` | `80` | Applies to JPEG only. |
| `maxWidth`, `maxHeight` | `Int?` | `null` | Downscales to fit, keeping the aspect ratio. Smaller images are never upscaled. |

On Android, the EXIF orientation is applied before resizing, so the output is upright.

## Save to the gallery

<Platforms scope="core" supported="android ios" partial={{ macos: 'Writes to the Pictures or Videos folder', jvm: 'Writes to the Pictures or Videos folder', linux: 'Writes to the Pictures or Videos folder', windows: 'Writes to the Pictures or Videos folder' }} anchor="filekit-core" />

`saveImageToGallery` and `saveVideoToGallery` return a `Result<Unit>` instead of throwing:

```kotlin nonWebMain
FileKit.saveImageToGallery(file = photo)
    .onFailure { error -> showError(error.message) }

FileKit.saveVideoToGallery(file = video, filename = "holiday.mp4")
```

`filename` defaults to the file's name. `saveImageToGallery(bytes, filename)` saves an image from memory.

| Platform | Destination |
| --- | --- |
| Android | MediaStore, in `DCIM/<app name>` on Android 10 and later. |
| iOS | The Photos library. `filename` is ignored. |
| macOS, JVM, Linux native, Windows native | The user's Pictures folder for images and Videos (Movies on macOS) folder for videos. |
| watchOS | Returns a failed `Result`. |
| Web | Not declared. |

<Warning>
On iOS, add `NSPhotoLibraryAddUsageDescription` to your `Info.plist` before saving to the gallery. Without it, the system terminates your app on the first save.
</Warning>

<Note>
On Android 9 and lower, writing to MediaStore requires the `WRITE_EXTERNAL_STORAGE` permission. FileKit doesn't declare it, so add it to your manifest with `android:maxSdkVersion="28"` if you support those versions.
</Note>

## Convert to and from ImageBitmap in Compose

<Platforms scope="compose" supported="android ios macos jvm web" anchor="compose-and-coil" />

`PlatformFile.toImageBitmap()` and `ImageBitmap.encodeToByteArray()` come from `filekit-dialogs-compose`, not `filekit-core`. Add it to `commonMain` (see [Installation](/installation) for the current version):

```kotlin build.gradle.kts
implementation("io.github.vinceglb:filekit-dialogs-compose:<version>")
```

```kotlin
import io.github.vinceglb.filekit.dialogs.compose.util.encodeToByteArray
import io.github.vinceglb.filekit.dialogs.compose.util.toImageBitmap

val bitmap: ImageBitmap = file.toImageBitmap()
val png: ByteArray = bitmap.encodeToByteArray(format = ImageFormat.PNG)
```

Both are suspend functions. `encodeToByteArray` defaults to `ImageFormat.JPEG` with `quality = 100`. To display a file in an `Image`, the [Coil](/integrations/coil) loads it for you, with caching.
