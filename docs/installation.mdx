FileKit is published on Maven Central under the `io.github.vinceglb` group. Add the modules you need to your shared module's `commonMain` dependencies.

## Choose your modules

| You want to… | Add |
| --- | --- |
| Show native pickers and save dialogs from Compose | `filekit-dialogs-compose` |
| Show native dialogs from ViewModels, shared logic, or non-Compose UI | `filekit-dialogs` |
| Read, write, and manage files without dialogs | `filekit-core` |
| Display a `PlatformFile` image with Coil 3 | `filekit-coil` |

`filekit-dialogs-compose` includes `filekit-dialogs`, which includes `filekit-core`.

## Supported targets

| Platform | Kotlin targets |
| --- | --- |
| Android | Android, minSdk 24 |
| iOS | `iosArm64`, `iosSimulatorArm64` |
| macOS | `macosArm64` |
| JVM desktop | `jvm` (JVM 17) on Windows, macOS, and Linux |
| Linux native | `linuxX64`, `linuxArm64` (core and dialogs) |
| Windows native | `mingwX64` (core and dialogs) |
| watchOS | `watchosArm64`, `watchosDeviceArm64`, `watchosSimulatorArm64` (core only) |
| Web | `js`, `wasmJs` (browser) |

Not every feature exists on every platform. Check the [platform support matrix](/platform-support) before calling an API from `commonMain`.

## Platform setup

Most targets need no setup. Do these steps once per app:

| Platform | `filekit-core` | `filekit-dialogs` | `filekit-dialogs-compose` |
| --- | --- | --- | --- |
| Android | Automatic (App Startup) | `FileKit.init(activity)` in your activity | Automatic |
| JVM desktop | `FileKit.init(appId)` | `FileKit.init(appId)`, plus `jdk.security.auth` on Linux | Same as dialogs |
| Linux native | `FileKit.init(appId)` | `FileKit.init(appId)`, plus `libdbus-1` | Not available |
| Windows native | `FileKit.init(appId)` | `FileKit.init(appId)` | Not available |
| iOS, macOS, JS, Wasm | None | None | None |
| watchOS | None | Not available | Not available |
