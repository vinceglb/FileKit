[Krop](https://github.com/tamimattafi/krop) is a third-party image cropping library for Compose Multiplatform. Its FileKit extension turns a `PlatformFile` into a Krop image source.

## Usage

Add Krop and its FileKit extension:

```kotlin build.gradle.kts
implementation("com.attafitamim.krop:core:<version>")
implementation("com.attafitamim.krop:extensions-filekit:<version>")
```

Pick an image with FileKit, then hand it to Krop with `toImageSrc()`:

```kotlin
scope.launch {
    val file = FileKit.openFilePicker(type = FileKitType.Image) ?: return@launch
    val imageSrc = file.toImageSrc()
    // Pass imageSrc to Krop's image cropper
}
```

See the [Krop README](https://github.com/tamimattafi/krop) for the cropper setup, supported platforms, and the current version. Once cropped, save the result with the [file saver](/dialogs/file-saver) or [compress it](/core/image-and-video-utils) first.
