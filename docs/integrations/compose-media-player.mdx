[Compose Media Player](https://github.com/kdroidFilter/ComposeMediaPlayer) is a third-party video player for Compose Multiplatform. Its player state opens a FileKit `PlatformFile` directly, with no extra module.

## Usage

```kotlin build.gradle.kts
implementation("io.github.kdroidfilter:composemediaplayer:<version>")
```

Pick a video with FileKit, then open it in the player:

```kotlin
scope.launch {
    val file = FileKit.openFilePicker(type = FileKitType.Video) ?: return@launch
    playerState.openFile(file)
}
```

`playerState` is the library's video player state. See the [Compose Media Player README](https://github.com/kdroidFilter/ComposeMediaPlayer) for the current version, the player composable, and supported platforms.
