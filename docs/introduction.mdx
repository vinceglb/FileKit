**FileKit is the file layer for Kotlin Multiplatform.** Open native file, photo, directory, and camera pickers, save and share files, and read or write them through a single `PlatformFile` type. The same code runs on Android, iOS, macOS, desktop JVM (Windows, macOS, Linux), Linux and Windows native, JS, and Wasm, and FileKit Core also runs on watchOS.

## FileKit in 30 seconds

Let the user pick a photo, then show it or read its bytes.

<CodeGroup>

```kotlin Compose
@Composable
fun PhotoPicker() {
    val scope = rememberCoroutineScope()
    var photo by remember { mutableStateOf<ImageBitmap?>(null) }

    val launcher = rememberFilePickerLauncher(
        type = FileKitType.Image,
        onError = { failure -> println("Picker failed: ${failure.message}") },
    ) { file ->
        // null when the user cancels
        if (file != null) scope.launch { photo = file.toImageBitmap() }
    }

    Button(onClick = { launcher.launch() }) { Text("Pick a photo") }
    photo?.let { Image(bitmap = it, contentDescription = null) }
}
```

```kotlin Suspend API
suspend fun importPhoto() {
    // Native picker on every platform; null when the user cancels
    val photo = FileKit.openFilePicker(type = FileKitType.Image) ?: return

    println("${photo.name}: ${photo.size()} bytes")

    // Read it, then upload it or store it
    val bytes: ByteArray = photo.readBytes()
}
```

## Platforms

| Android | iOS | macOS | JVM desktop | Linux native | Windows native | JS | Wasm | watchOS |
| :-----: | :-: | :---: | :---------: | :----------: | :------------: | :-: | :--: | :-----: |
| ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | Core only |

Every target with `filekit-dialogs` uses the platform's native dialogs (watchOS has FileKit Core only). Some features are platform-specific: the camera and share sheet are mobile-only, the file saver is not available in browsers, and Compose and Coil support follows Compose Multiplatform's targets. See the [platform support matrix](/platform-support) for a feature-by-feature breakdown.

## Modules

Add only the modules you need. Each module pulls in the ones it builds on.

| Artifact | What it gives you | Add it when |
| --- | --- | --- |
| `filekit-core` | `PlatformFile`, reading and writing, file system operations, app directories, image utilities, bookmarks | You work with files and don't need dialogs |
| `filekit-dialogs` | Native file, gallery, directory, and camera pickers, plus the file saver, share, and open-file dialogs, as `suspend` functions | You open dialogs from shared code, ViewModels, or non-Compose UI |
| `filekit-dialogs-compose` | `remember…Launcher` APIs and `PlatformFile.toImageBitmap()` | Your UI uses Compose Multiplatform |
| `filekit-coil` | `PlatformFile` support in Coil 3 `AsyncImage` | You display images with Coil |
