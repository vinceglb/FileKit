FileKit ships in apps on mobile, desktop, and the web. Each entry says how the project uses FileKit and links to a public source: the build file that declares the dependency or, for closed-source apps, the developer's own post.

## Trusted by

<CardGroup cols={2}>
  <Card title="Thunderbird">
    Thunderbird for Android and K-9 Mail use FileKit Core in their logging stack to write and export sync debug logs. Included from Thunderbird 26, currently in Daily builds. [Source](https://github.com/thunderbird/thunderbird-android/blob/main/app-common/build.gradle.kts)
  </Card>
  <Card title="Leboncoin">
    Spark, Leboncoin's Android design system, builds its FileUpload components on FileKit pickers. [Source](https://github.com/leboncoin/spark-android/blob/main/spark/build.gradle.kts)
  </Card>
  <Card title="Gradle">
    Gradle Client, a desktop app for the Gradle Tooling API, picks build directories with FileKit. [Source](https://github.com/gradle/gradle-client/blob/main/gradle-client/build.gradle.dcl)
  </Card>
  <Card title="Blockstream Green">
    The Green Bitcoin wallet imports and exports PSBT files and shares files with FileKit, on Android and desktop. [Source](https://github.com/Blockstream/green_android/blob/master/data/build.gradle.kts)
  </Card>
  <Card title="Square">
    `workflow-trace-viewer`, an internal desktop tool in the Workflow repository, loads trace files with the FileKit file picker. [Source](https://github.com/square/workflow-kotlin/blob/main/workflow-trace-viewer/build.gradle.kts)
  </Card>
  <Card title="Android FHIR SDK">
    The project started by Google, now under the OHS Software Foundation, uses FileKit camera and file pickers for attachments in its in-progress multiplatform Structured Data Capture module. [Source](https://github.com/ohs-foundation/android-fhir/blob/master/datacapture-kmp/build.gradle.kts)
  </Card>
  <Card title="DroidKaigi">
    The official DroidKaigi 2025 conference app picks profile images with FileKit and loads them with Coil. [Source](https://github.com/DroidKaigi/conference-app-2025/blob/main/feature/profile/build.gradle.kts)
  </Card>
  <Card title="Mifos">
    Open source banking apps for Apache Fineract upload ID, KYC, and loan documents with FileKit: [Mifos Mobile](https://github.com/openMF/mifos-mobile/blob/dev/feature/auth/build.gradle.kts), [Mifos Pay](https://github.com/openMF/mifos-pay/blob/dev/feature/kyc/build.gradle.kts), and [Mifos X Field Officer](https://github.com/openMF/mifos-x-field-officer-app/blob/dev/feature/client/build.gradle.kts).
  </Card>
  <Card title="OSS Review Toolkit">
    ORT Workbench, the desktop viewer for ORT results, opens result files and directories with FileKit dialogs. [Source](https://github.com/oss-review-toolkit/ort-workbench/blob/main/build.gradle.kts)
  </Card>
  <Card title="Scanbot SDK">
    The official Kotlin Multiplatform example app for the Scanbot SDK picks images and PDFs with FileKit. [Source](https://github.com/doo/scanbot-sdk-example-kmp/blob/main/composeApp/build.gradle.kts)
  </Card>
</CardGroup>
