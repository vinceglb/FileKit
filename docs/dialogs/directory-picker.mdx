`openDirectoryPicker` shows the platform's native folder dialog and returns the selected folder as a `PlatformFile`.

## Usage

<CodeGroup>

```kotlin Compose
val launcher = rememberDirectoryPickerLauncher(
    onError = { failure -> showError(failure.message) },
) { directory ->
    // directory is a PlatformFile, or null when the user cancelled
}

Button(onClick = { launcher.launch() }) {
    Text("Pick a folder")
}
```

```kotlin Suspend API
val directory: PlatformFile? = FileKit.openDirectoryPicker()
```

</CodeGroup>

<DialogResult />

## Options

| Parameter | Values | Default | Notes |
| --- | --- | --- | --- |
| `directory` | `PlatformFile?` | `null` | Folder the dialog opens in. Ignored on the web. |
| `dialogSettings` | `FileKitDialogSettings` | `createDefault()` | Title, parent window, and other [per-platform settings](/dialogs/dialog-settings). |

In Compose, pass these options to `rememberDirectoryPickerLauncher`. `launch()` takes no arguments.

## Read the folder's contents

Call `list()` for the direct children or `walk()` for the whole tree. See [File operations](/core/file-operations#list-a-directory).

## Keep access across launches

A picked folder is only accessible for the current session on Android and Apple platforms. Save its bookmark to reopen it after a restart:

```kotlin nonWebMain
val directory = FileKit.openDirectoryPicker() ?: return
val bookmark = directory.bookmarkData()
saveBytes("project_folder", bookmark.bytes)

// After a restart
val restored = PlatformFile.fromBookmarkData(loadBytes("project_folder"))
```

`saveBytes` and `loadBytes` stand for your own storage. See [Bookmark data](/core/bookmark-data) for invalid bookmarks and security-scoped access on Apple platforms.

## Platform notes

| Platform | Behavior |
| --- | --- |
| Android | Storage Access Framework tree picker. The result is a `content://` tree URI. |
| iOS | `UIDocumentPickerViewController` in folder mode. |
| macOS | `NSOpenPanel` configured for folders. |
| JVM | Native dialog on macOS and Windows, and the XDG Desktop Portal on Linux with a Swing fallback when no portal runs. |
| Linux native | XDG Desktop Portal only, with no fallback dialog. See [Linux setup](/dialogs/setup#linux-setup). |
| Windows native | `IFileDialog` in folder mode. |
| Web | Browsers expose the folder as a flat file list, so FileKit rebuilds a read-only tree from relative paths. Empty subfolders are missing, folders report a `lastModified()` of epoch `0`, and an empty folder returns `null`, like a cancellation. |
