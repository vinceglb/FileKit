Open the native save dialog. FileKit returns the location the user picked as a `PlatformFile`, and you write your data to it. The file saver is not available on the web, so call it from a non-web source set such as `nonWebMain` (see [shared source sets](/platform-support#use-platform-specific-apis-from-shared-code)).

## Usage

<CodeGroup>

```kotlin Compose
val scope = rememberCoroutineScope()
val launcher = rememberFileSaverLauncher(
    dialogSettings = FileKitDialogSettings.createDefault(),
    onError = { failure -> showError(failure.message) },
) { file ->
    scope.launch { file?.writeString("Hello FileKit!") }
}

Button(onClick = { launcher.launch(suggestedName = "notes", defaultExtension = "txt") }) {
    Text("Save")
}
```

```kotlin Suspend API
val file = FileKit.openFileSaver(suggestedName = "notes", defaultExtension = "txt")
file?.writeString("Hello FileKit!")
```

</CodeGroup>

## Options

<ResponseField name="suggestedName" type="String" post={["required", "launch()"]}>
  File name without the extension.
</ResponseField>

<ResponseField name="defaultExtension" type="String?" default="null" post={["launch()"]}>
  Extension without the dot, appended to `suggestedName`.
</ResponseField>

<ResponseField name="allowedExtensions" type="Set<String>?" default="null" post={["launch()"]}>
  Save types offered by the dialog, without dots. A hint, not a validation.
</ResponseField>

<ResponseField name="directory" type="PlatformFile?" default="null" post={["launch()"]}>
  Initial folder. Ignored on Android.
</ResponseField>

<ResponseField name="dialogSettings" type="FileKitDialogSettings" default="createDefault()" post={["rememberFileSaverLauncher"]}>
  Required by the Compose launcher. In a Compose Desktop `Window`, `WindowScope.rememberFileSaverLauncher` makes it optional and parents the dialog to the window. See [Dialog settings](/dialogs/dialog-settings).
</ResponseField>

## Offer several file types

Pass `allowedExtensions` to let the user pick a format. `defaultExtension` stays the preselected one:

```kotlin
val file = FileKit.openFileSaver(
    suggestedName = "report",
    defaultExtension = "pdf",
    allowedExtensions = setOf("pdf", "txt"),
)
```

Not every platform enforces the filter, so check `file.extension` if your app needs a specific format.

## Download file on the web

Browsers don't let you choose a save location: use `FileKit.download` to send bytes to the user's downloads folder instead. See [Download files](/core/web#download-files).

## Platform notes

| Platform | Behavior |
| --- | --- |
| Android | Opens the system "Create document" screen, which creates an empty file at the chosen location. With several `allowedExtensions`, the MIME type falls back to `*/*`. |
| iOS | Exports a temporary placeholder file through the Files picker, then removes it so you can write to the returned location. `allowedExtensions` is ignored. |
| Desktop | The save dialog shows `dialogSettings.title` on Linux native, Windows native, and JVM on macOS. The macOS native saver and the JVM savers on Windows and Linux ignore it. |
| Linux native | Needs a running XDG Desktop Portal. See [Dialogs setup](/dialogs/setup#linux-setup). |
| Web | Not available. Use `FileKit.download`. |

<Accordion title="Upgrading from older versions">
  The `extension` parameter of `openFileSaver` and `launch()` is deprecated. Rename it to `defaultExtension`; the behavior is the same.
</Accordion>
