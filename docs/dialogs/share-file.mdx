Open the system share sheet so the user can send files to another app. Call it from a source set that only includes Android and iOS, such as `mobileMain` (see [shared source sets](/platform-support#use-platform-specific-apis-from-shared-code)).

## Usage

<CodeGroup>

```kotlin Compose
val launcher = rememberShareFileLauncher(
    onError = { failure -> showError(failure.message) },
)

Button(onClick = { launcher.launch(FileKit.filesDir / "report.pdf") }) {
    Text("Share")
}
```

```kotlin Suspend API
FileKit.shareFile(FileKit.filesDir / "report.pdf")

// Several files at once
FileKit.shareFile(listOf(FileKit.filesDir / "a.jpg", FileKit.filesDir / "b.jpg"))
```

</CodeGroup>

Sharing has no result: a completed share and a dismissed sheet look the same. Failures go to `onError` in Compose, or are thrown as a `FileKitDialogException` by the suspend API. See [Results and errors](/dialogs/error-handling#sharing).

## Options

<ResponseField name="file / files" type="PlatformFile | List<PlatformFile>" post={["required", "launch()"]}>
  What to share. An empty list does nothing.
</ResponseField>

<ResponseField name="shareSettings" type="FileKitShareSettings" default="createDefault()" post={["rememberShareFileLauncher"]}>
  Platform-specific settings. In the suspend API, pass it to `shareFile()`.

  <Expandable title="properties">
    <ResponseField name="authority" type="String?" default="null" post={["Android"]}>
      FileProvider authority, only needed for files outside `filesDir` and `cacheDir`. When `null`, FileKit uses its bundled `${applicationId}.FileKitFileProvider`.
    </ResponseField>
    <ResponseField name="addOptionChooseIntent" type="(Intent) -> Unit" default="no-op" post={["Android"]}>
      Customizes the chooser `Intent` before it launches.
    </ResponseField>
    <ResponseField name="addOptionUIActivityViewController" type="(UIActivityViewController) -> Unit" default="no-op" post={["iOS"]}>
      Customizes the share sheet before it appears, for example `excludedActivityTypes`.
    </ResponseField>
    <ResponseField name="presenter" type="UIViewController?" default="null" post={["iOS"]}>
      View controller that presents the sheet. When `null`, the suspend API uses the top-most view controller and the Compose launcher uses the current `LocalUIViewController`.
    </ResponseField>
    <ResponseField name="metaTitle" type="String" default="&quot;Share File&quot;" post={["iOS"]}>
      Accepted but currently not applied to the share sheet.
    </ResponseField>
  </Expandable>
</ResponseField>

## Platform notes

| Platform | Behavior |
| --- | --- |
| Android | Files in `FileKit.filesDir`, `FileKit.cacheDir`, or returned by a picker (`content://`) share without setup. The MIME type comes from the file extensions, or `*/*` when they differ. The suspend call returns once the chooser opens. |
| iOS | The suspend call returns when the sheet closes. An error reported by the chosen activity fails with a `FileKitDialogException`. On iPad, the sheet opens as a popover centered on the presenter's view. |

## Android setup

<AndroidFileProviderSetup />

<Note>
A custom `authority` applies to every file in the share. If you share files from several directories at once, for example `filesDir` and `getExternalFilesDir()`, your provider's `file_paths.xml` must cover all of them. Otherwise FileKit throws an `IllegalArgumentException` before the share sheet opens.
</Note>
