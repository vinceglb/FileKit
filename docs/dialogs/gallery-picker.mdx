Pass `FileKitType.Image`, `Video`, or `ImageAndVideo` to the file picker. On Android and iOS it opens the system photo picker; on other targets it opens a file dialog filtered to media files.

## Usage

<CodeGroup>

```kotlin Compose
val launcher = rememberFilePickerLauncher(
    type = FileKitType.Image,
    onError = { failure -> showError(failure.message) },
) { image ->
    // image is a PlatformFile, or null when the user cancelled
}

Button(onClick = { launcher.launch() }) {
    Text("Pick a photo")
}
```

```kotlin Suspend API
val image: PlatformFile? = FileKit.openFilePicker(type = FileKitType.Image)
```

</CodeGroup>

<DialogResult />

Every [file picker option](/dialogs/file-picker#options) applies, including the state-tracking modes.

## What users see

| Platform | Dialog |
| --- | --- |
| Android | The system [Photo Picker](https://developer.android.com/training/data-storage/shared/photopicker). If the device has none, FileKit opens the document picker filtered by `image/*` or `video/*`. |
| iOS | [`PHPickerViewController`](https://developer.apple.com/documentation/photokit/selecting-photos-and-videos-in-ios). FileKit copies each selected item to a temporary directory before returning it. |
| macOS, JVM, Linux native, Windows native | The regular file dialog, filtered to `png`, `jpg`, `jpeg`, `gif`, `bmp` for images and `mp4`, `mov`, `avi`, `mkv`, `webm` for videos. |
| Web | `<input type="file">` with `accept` set to `image/*`, `video/*`, or both. |

## Limit the number of items

Use `FileKitMode.Multiple(maxItems)` with a value from `1` to `50`. The same `mode` works on `rememberFilePickerLauncher`:

```kotlin
val media: List<PlatformFile>? = FileKit.openFilePicker(
    type = FileKitType.ImageAndVideo,
    mode = FileKitMode.Multiple(maxItems = 5),
)
```

The Android and iOS pickers enforce the limit in their UI. File dialogs on other targets can't, so FileKit keeps the first `maxItems` files.

<Tip>
iOS can return photos as HEIC, which some image decoders and servers can't read. In `iosMain`, pass `FileKitDialogSettings(assetRepresentationMode = FileKitAssetRepresentationMode.Compatible)` as `dialogSettings` so iOS transcodes them to a more compatible format.
</Tip>
